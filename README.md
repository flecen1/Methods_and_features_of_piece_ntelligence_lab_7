## Запуск з командного рядка

```powershell
python main.py --variant 1 --generations 150 --population 40 --seed 7
python main.py --variant 1 --plot --plot-file figures\variant1.png --no-show
python main.py --variant 3 --json
```

Параметри:

- `--variant` — номер 1…5 (рядок таблиці варіантів у `variants.py` / у методичних вказівках).
- `--population` — розмір популяції (**не менше 2**).
- `--generations` — кількість поколінь (**не менше 1**).
- `--seed` — відтворюваність випадкових чисел (якщо не вказано, кожен запуск дає інший результат — це нормально для ГА).
- `--plot` — побудувати графік функції (1D — крива, 2D — поверхня).
- `--plot-file` — зберегти графік у файл; `--no-show` — не відкривати вікно matplotlib.

## GUI (завдання з графічним інтерфейсом)

```powershell
python gui.py
```

У формі задаються варіант, розмір популяції, кількість поколінь, опційно сід. Кнопка «Запустити ГА» показує текстовий результат і графіки: функція / контури та історія збіжності.

## Відповіді на контрольні питання (коротко)

1. **Особливості ГА:** пошук із популяції, використання лише значень цільової функції (без градієнтів), стохастичні правила відбору, ітеративне «еволюційне» покращення наближення.

2. **Генетичні оператори:** селекція (відбір батьків), схрещування (кросовер), мутація; часто також елітизм і стратегії заміни популяції.

3. **Критерії зупинки:** ліміт поколінь; ліміт часу; поріг якості; відсутність покращення протягом кількох поколінь; мала відносна зміна найкращого значення тощо. У цьому репозиторії використовується зупинка за кількістю поколінь.

4. **Схема класичного ГА:** ініціалізація популяції → оцінка пристосованості → перевірка критерію зупинки → селекція → застосування кросоверу та мутації → формування нового покоління → повторення.

5. **Спільне використання операторів:** кросовер комбінує успішні фрагменти рішень; мутація підтримує різноманітність і допомагає виходити з локальних екстремумів; селекція направляє пошук; їх баланс впливає на швидкість збіжності і ризик передчасної збіжності.

## Примітка щодо варіантів 2 і 4

Для раціональної функції з знаменниками `(x−3)` та `(x−1)` на відрізку `[−4; 8]` є полюси. У коді для стійкості додано **штраф** у малих околах `x=1` та `x=3`. У звіті варто згадати це або показати графік з виключеними околами полюсів.
